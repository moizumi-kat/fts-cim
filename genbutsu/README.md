# いただいた現物（加工しないで置く）

ここは **村上様・ＩＴ管理室からいただいたものを、そのまま**置く場所です。
解析した結果ではなく、元のバイト列を残します。失うと再入手に時間がかかるためです。

## 20261107_画面定義とA10CPYPO

2026-11-11 受領。見積登録（工程11-1）の画面定義6本と、7本が共有する受け渡し領域。

    A10040D1.SMD   鑑画面        8,960 バイト
    A10050D1.SMD   概算画面      5,888
    A10060D1.SMD   項目画面      8,960
    A10070D1.SMD   項目明細画面  9,984
    A10080D1.SMD   凾体画面      2,816
    A10090D1.SMD   科目画面      3,840
    A10CPYPO.COB   受け渡し領域  1,128（テキスト・cp932）

`.SMD` は**オフコンのオブジェクト形式**で、PCで開いても読めません。
中身は **EBCDIC**（先頭8バイトが画面名）。読みかたは `bin/smd_parse.py`、
読み取りが正しいかの検算は `bin/smd_kensan.py`。

    python3 -I bin/smd_parse.py  genbutsu/20261107_画面定義とA10CPYPO/A10080D1.SMD
    python3 -I bin/smd_kensan.py genbutsu/20261107_画面定義とA10CPYPO <現行ソースのフォルダ>
