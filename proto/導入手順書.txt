================================================================
 FTS-CIM  Python版 試作   導入手順書
================================================================

 ＜もくじ＞
   1. 用意するもの
   2. Python を入れる（初回だけ・1台につき1回）
   3. このフォルダを置く
   4. 「はじめて実行.bat」を1回だけ動かす
   5. 「起動.bat」で立ち上げる
   6. 終わらせかた
   7. 2回目からは
   8. ほかのパソコンからも見たいとき
   9. データの場所・バックアップ・入れ直し
  10. うまくいかないとき
  11. 数字が合っているか確かめる／結果の送り方
  12. SQL Server につなぐとき（情報システムご担当者向け）

 ※ 社内サーバに置いて、各自はブラウザだけで使う形にする場合は、
    この手順書ではなく「サーバ導入手順書.txt」をご覧ください。
    各パソコンへのインストールは不要になります。


----------------------------------------------------------------
 1. 用意するもの
----------------------------------------------------------------

   ・Windows のパソコン（10 または 11）
   ・Python 3.13           … 2 で入れます（新しすぎると入らない部品があります）
   ・ブラウザ（Edge / Chrome など）

   インターネットにつながっていなくても動きます。
   必要な部品（Flask）は vendor フォルダに同梱してあります。


----------------------------------------------------------------
 2. Python を入れる（初回だけ・1台につき1回）
----------------------------------------------------------------

   すでに Python が入っているパソコンでは、この手順は不要です。
   （確かめ方：10-(1) を参照）

   (1) ブラウザで  https://www.python.org/downloads/windows/  を開く

   (2) **Python 3.13** の Windows installer (64-bit) をダウンロードする

       ※ いちばん新しい版（3.15 など）だと、SQL Server につなぐ部品が
          入らないことがあります。3.13 をお選びください。

   (3) ダウンロードしたファイルをダブルクリック

   (4) ★ここが大事です★
       最初の画面の下にある

           [v] Add python.exe to PATH

       に 必ずチェックを入れてから 「Install Now」を押す

       （ここにチェックを入れ忘れると、あとの手順で
         「python は認識されていません」と出ます）

   (5) 「Setup was successful」と出たら閉じる


----------------------------------------------------------------
 3. このフォルダを置く
----------------------------------------------------------------

   (1) 届いた zip ファイルを右クリック →「すべて展開」

   (2) 展開先は デスクトップ か ドキュメント をおすすめします

   (3) 展開してできた
         FTS-CIM 試作一式 ＞ 01_ソフト
       を開く

   ※ zip の中身のまま（展開せずに）動かすことはできません。
      かならず展開してください。


----------------------------------------------------------------
 4. 「はじめて実行.bat」を1回だけ動かす
----------------------------------------------------------------

   01_ソフト の中の

        はじめて実行.bat

   をダブルクリックします。

   黒い画面が出て、部品の取り込みとデータベースの作成が行われます。
   「準備ができました」と出たら、何かキーを押して閉じてください。

   ・1分ほどかかることがあります
   ・「Windows によって PC が保護されました」と出たときは
     「詳細情報」→「実行」を押してください
   ・この作業は、そのパソコンで最初の1回だけです


----------------------------------------------------------------
 5. 「起動.bat」で立ち上げる
----------------------------------------------------------------

   01_ソフト の中の

        起動.bat

   をダブルクリックします。

   黒い画面が出て、しばらくするとブラウザが開き、
   FTS-CIM の画面が表示されます。

   ブラウザが自動で開かないときは、ブラウザのアドレス欄に

        http://127.0.0.1:5000

   と入れてください。

   ★ 黒い画面は閉じないでください。
      これが動いている間だけ、ブラウザで見られます。


----------------------------------------------------------------
 6. 終わらせかた
----------------------------------------------------------------

   黒い画面を閉じる（×ボタン）だけです。
   ブラウザも閉じてかまいません。

   記録した聞き取りの内容は保存されています（9 を参照）。


----------------------------------------------------------------
 7. 2回目からは
----------------------------------------------------------------

   「起動.bat」をダブルクリックするだけです。
   「はじめて実行.bat」はもう要りません。

   よく使うようでしたら、「起動.bat」を右クリック →
   「ショートカットの作成」でデスクトップに置いておくと便利です。


----------------------------------------------------------------
 8. ほかのパソコンからも見たいとき
----------------------------------------------------------------

   聞き取りで、1台を立ち上げて何人かで見たいときは、

        社内LANに公開して起動.bat

   をダブルクリックしてください。
   黒い画面に出てくるアドレス（http://192.168.～:5000 のような形）を、
   ほかのパソコンのブラウザに入れると開きます。

   ★ご注意
     このソフトにはログイン機能がありません。
     社内LANにつながっている方なら誰でも見られます。
     聞き取りの場かぎりでお使いになり、
     終わったら黒い画面を閉じてください。

   ・初回は「ファイアウォールでブロックされました」と出ることがあります。
     「プライベートネットワーク」にチェックを入れて「アクセスを許可する」
     を押してください。


----------------------------------------------------------------
 9. データの場所・バックアップ・入れ直し
----------------------------------------------------------------

   データは 01_ソフト の中の

        ftscim.db

   というファイル1個に入っています。
   聞き取りの記録も、目標メンテで登録した金額も、すべてここです。

   ・バックアップ … このファイルをコピーしておくだけです
   ・ほかのPCへ移す … このファイルを持っていけばそのまま使えます
   ・最初の状態に戻す … ftscim.db を削除して「起動.bat」を実行
                        （※ 記録した聞き取りも消えます。先にコピーを）

   聞き取りの記録は、画面右下「一覧」→「CSVで取り出す」で
   Excel に取り出せます。こちらも定期的にどうぞ。


----------------------------------------------------------------
 10. うまくいかないとき
----------------------------------------------------------------

   (1)「python は認識されていません」と出る

       Python が入っていないか、2-(4) のチェックを
       入れ忘れています。
       Python を入れ直し、「Add python.exe to PATH」に
       必ずチェックを入れてください。

       ＜確かめ方＞
         スタートボタン →「cmd」と入力 → コマンドプロンプトを開く
         python --version   と入れて Enter
         → 「Python 3.11.x」のように出れば入っています

   (2) 黒い画面がすぐ消える

       「はじめて実行.bat」を先に動かしてください。
       それでも消える場合は、黒い画面の最後に出ている
       メッセージを控えてご連絡ください。

   (3)「ポートが使用中です」「Address already in use」と出る

       すでに起動している黒い画面がないか確かめてください。
       それでも出るときは、別の番号で動かせます。
       コマンドプロンプトを開いて、01_ソフト のフォルダへ移動し

           set PORT=5050
           python run.py

       と入れてください。ブラウザは http://127.0.0.1:5050 です。

   (4) 画面が文字化けする

       ブラウザの再読み込み（F5）をお試しください。
       それでも直らないときはご連絡ください。

   (5) ブラウザに何も出ない

       黒い画面に
           → http://127.0.0.1:5000
       と出ているか確かめ、その通りにアドレスを入れてください。


----------------------------------------------------------------
 11. 数字が合っているか確かめる
----------------------------------------------------------------

        確認.bat

   をダブルクリックすると、画面に出る数字が
   現物の紙と合っているかを全項目つき合わせます。

   最後に「すべて一致しました。」と出れば正常です。

   ・営業日報の8営業所・部計・総合計・生産実績
   ・日報内訳の受注／出図／売上の各合計
   ・受注率の式（受注金額 ÷ 総原価 ×100）と、
     計は率を平均せず金額と原価を足してから割ること
   ・達成率の切り捨て
   ・画面遷移Ｇの分岐（物件検討ファイルに製番があるか）

   結果をお知らせいただく場合は

        確認結果を保存.bat

   をダブルクリックすると、同じフォルダに 確認結果.txt ができます。
   このファイルをそのままお送りください
   （パスワードは伏せ字で出力されます）。


----------------------------------------------------------------
 12. SQL Server につなぐとき（情報システムご担当者向け）
----------------------------------------------------------------

   いまは SQLite（ファイル1個のSQLデータベース）で動いています。
   SQL Server に向けるときに触るのは 2か所だけです。

   (1) cim\config.py

         DRIVER = 'mssql'     に変える

   (2) 接続文字列を 環境変数 FTSCIM_DSN に置く

         例）
         set FTSCIM_DSN=DRIVER={ODBC Driver 18 for SQL Server};
             SERVER=<ホスト名>;DATABASE=FTSCIM;UID=<利用者>;
             PWD=<パスワード>;TrustServerCertificate=yes

       ※ パスワードはソースに書きません。環境変数から読みます。

   (3) pip install pyodbc

   表の定義（cim\db.py の SCHEMA）と SQL文（cim\repo.py）は
   どちらのデータベースでもそのまま通る書き方にしてあります。
   cim\repo.py の書き換えは不要です。

   社内サーバ＋SQL Server の構成で入れる場合の、通しの手順は
   「サーバ導入手順書.txt」にまとめてあります。
   技術的な中身は README.md をご覧ください。

 付録B：bat ファイルが入っていない場合（コマンドでの実行）
----------------------------------------------------------------

   メール・チャット・クラウドの多くは、実行ファイル（.bat など）を
   含む圧縮ファイルを自動で止めます。そのため、送付の都合で
   bat ファイルと vendor フォルダを外した版をお渡しすることがあります。

   その場合も、コマンドプロンプトで同じことができます。

     スタート →「cmd」→ コマンドプロンプトを開き、

        cd /d C:\FTSCIM          ← ファイルを置いた場所

     を実行してから、下の表のコマンドを打ってください。

     bat ファイル            同じことをするコマンド
     --------------------    ------------------------------------
     はじめて実行.bat        python -m pip install -r requirements.txt
                             python run.py --seed
     接続確認.bat            python dbcheck.py
     確認.bat                python verify.py
     確認結果を保存.bat      python report.py
     サーバとして起動.bat    python serve.py
     起動.bat                python run.py
     社内LANに公開して起動   set FTSCIM_HOST=0.0.0.0
                             python run.py

   ■ vendor フォルダ（Python部品）が入っていない場合

     インターネットにつながるサーバなら、これだけです。

        python -m pip install -r requirements.txt

     つながらないサーバの場合は、つながる別のPCで

        python -m pip download -r requirements.txt -d vendor --platform win_amd64 --python-version 3.11 --only-binary=:all:

     として vendor フォルダを作り、サーバへコピーしてから

        python -m pip install --no-index --find-links vendor -r requirements.txt

     としてください。
     （Python のバージョンが 3.11 以外の場合は、その番号に変えてください）
